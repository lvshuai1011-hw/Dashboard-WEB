# 问结算助手前端设计

## 从一条回答读懂这套代码

假设用户问“各计费类型的收入占比是多少”。同一条连接可能先返回分析文字，再返回图表 JSON、几段总结，最后发来结束信号和追问。前端要同时回答三个问题：这条数据属于哪条消息、它表示什么、此刻该把它画在哪里。分别处理这三个问题，才能让用户在图表刚出现时就读到下方的总结，也能在刷新后还原相同的顺序。

下表路径均相对于 `src/views/ux/aiAgent/`。

| 需要修改的行为 | 先读这里 | 这里负责什么 |
| --- | --- | --- |
| 发送、停止、重新生成 | `composables/useChatStream.ts` | 创建消息，登记请求句柄，处理完成、错误和迟到的追问 |
| 识别服务端事件 | `lib/sse.ts`、`lib/streamEvents.ts` | 前者拼出完整事件，后者将业务事件写入当前助手消息 |
| 总结出现在图表上方或下方 | `lib/messageLayout.ts` | 将收到的步骤分给正文或可折叠的过程区 |
| 图表类型、空态、导出 | `lib/chartSchema.ts`、`lib/chartOptions.ts`、`components/ChartView.vue` | 依次负责输入校验、数据映射和图表实例生命周期 |
| 编辑提问、切换会话、找回阅读位置 | `composables/useQuestionEditor.ts`、`useConversations.ts`、`useScrollFollow.ts` | 分开维护编辑前的草稿、会话集合和滚动位置 |
| 更换图标或调整弹层 | `assets/icons/`、`styles/global.less` | 单个 SVG 决定形状，样式控制颜色、尺寸及挂在页面外的浮层 |
| 变更上传格式或解析上限 | `types.ts`、`composables/useAttachments.ts`、`lib/attachmentReaders.ts` | 对齐选择器、读取校验、错误文案和实际读取器 |

## 消息如何从请求变成界面

1. `App.vue` 把输入框、侧栏和消息列表接到同一组会话操作。发送时，`useChatStream` 先登记助手消息和取消句柄，再启动网络请求。回调持有发起时的会话与消息对象，因此切换侧栏后，后台回答仍然写回原会话。每个会话同时生成一条答复，整个页面最多三条。
2. `chatStream` 从宿主登录状态取得 CSRF 信息，通过 POST 读取 SSE 字节流。UTF-8 解码器保留跨块字符，分帧器缓存半行，遇到空行才派发完整事件。先读外层事件和错误类型，再解出内层事件与消息标识。只收到子任务结束就断流会报错，主请求完成需要有效的结束帧。等待响应头和等待后续字节均受空闲超时约束。
3. 文本增量按服务端消息标识追加到相应文本轮。工具、子任务和图表成为独立步骤。首张有效图表也是文本轮的边界，即使服务端前后用了相同标识，图后的总结也会开启新一轮。图表结构校验失败时保留普通 JSON 步骤，读者仍可展开查看。
4. `layout()` 按接收顺序分成过程区与正文区。有图表时，图表和之后的文本立即进入正文。纯文本回答在完成时采用最终文本轮。追问通过对象的 `follow_up` 字段识别，和 JSON 是第几个到达无关。
5. 主回答完成即可结束生成状态并持久化结果。需要等追问时，连接最多续留 20 秒，只接收追问 JSON。等待期间不占生成名额。切换会话无需取消其他回答，离开页面时清理活动请求和计时器。

## 图表、文字与交互

`MessageItem.vue` 消费布局结果，把过程交给 `ProcessTimeline.vue`，把图表交给 `ChartCard.vue`，把正文交给 `Typewriter.vue`。查“为什么这段话进了思考区”应先核对事件类型和布局结果；改字体或图表间距则从消息模板和样式入手。

柱状图和折线图按数据首次出现的顺序建立类目轴，再把每个系列对齐到这些类目。缺失值保留为空，避免画出不存在的零。服务端的轴编号可以不连续，绘制前转换成 ECharts 的数组下标。导出图片需要临时加入标题和边距，导出结束或失败都会恢复当前图表。卡片用消息标识和步骤标识的组合来定位实例，因为步骤编号只在一条消息内唯一。

打字机保存已显示文本和待输出文本。Markdown 渲染在生成 HTML 之前转义普通文字和代码，链接只接受允许的协议。代码着色把注释、引号字符串、数字和词分别匹配，着色不改变复制到剪贴板的代码。流式期间重点文本先加粗；本轮正文完成后等待布局稳定，再播放 0.8 秒的高亮扫过效果。迟到的追问不参与计时。减少动态时直接显示正文。

## 历史与附件

`useConversations.ts` 管理会话集合、当前选中项和保存时机。`lib/history.ts` 在读入本地历史时筛掉无效行，修复重复消息标识，并重验历史图表。刷新会断开传输，原先运行中的消息按已停止恢复；旧记录没有最终轮标记时，尝试从最后一次工具或子任务之后恢复正文。搜索、复制与正文布局共用消息内容的提取规则，避免用户能看到的图表标题搜不到。

添加附件时记住发起读取的会话。异步读取返回后先核对该会话仍存在，再附到它的草稿。每条问题最多五个文件，单文件上限为 5 MiB；提取后的文本也按 UTF-8 字节数检查。发送时把附件文本和问题组合到现有的 `message.content`。本地历史单独保存附件元数据和提取文本，以便预览。

| 输入 | 读取过程与边界 |
| --- | --- |
| 纯文本、代码、CSV | 按 UTF-8 严格解码，空内容或含零字节的内容会被拒绝。 |
| PDF | `pdfReader.ts` 延迟加载 PDF.js，逐页读取文本层。资源跟随站点打包。读取最多 200 页，有 30 秒超时；扫描图片需要另行 OCR。 |
| DOCX、XLSX、PPTX | 三者均把 XML 文档放在 ZIP 容器内。`officeArchive.ts` 先从文件尾定位中央目录，再按目录中的名称找到本地文件头和数据段。检查边界、压缩方式、解压长度与 CRC 后才解析 XML。目录最多 4096 项，声明解压总量最多 24 MiB。 |
| Office 内部文档 | `officeXml.ts` 处理 XML 与关系路径；`officeReaders.ts` 按段落、工作表或幻灯片组织文本。工作表保留稀疏行号，优先使用公式缓存值，缺失时显示公式文本。日期和百分比格式来自 `spreadsheetFormats.ts`。 |

评阅 ZIP 代码时可从 `END_OF_CENTRAL_DIRECTORY` 开始。比如 `COMMENT_LENGTH` 是“记录起点到注释长度字段的偏移”，`FIXED_SIZE` 是“记录中固定部分的字节数”。二者加上读出的注释长度，才能确认找到的签名确实位于文件尾。更改文件格式字段时在记录定义处核对；4096 项这类应用容量限制则独立命名，便于单独调整。

## 如何更换图标

例如工具栏里的表格图标，对应 [table.svg](../src/views/ux/aiAgent/assets/icons/table.svg)。在 GitHub 打开文件即可预览。源图由一个圆角矩形、一条横线和一条竖线组成。只调整外观时编辑或替换这一张图，保留原文件名和视口即可。

组件通过 `lib/icons.ts` 中的 `TableIcon` 等名称引用图标。`global.less` 把相应的 SVG 用作遮罩，填色继承按钮文字的颜色，悬停、禁用和选中态因此可以共用一份图。新增图标时，在资源目录放入 SVG，在样式中关联文件名，再按调用方式导出组件。Markdown 代码块由 HTML 字符串生成，复制按钮复用同一套图标样式。生成中标识的圆点和圆环由 CSS 独立控制动画。

欢迎页示意图及自身的减少动态规则在 `assets/welcome-trend.svg`。真实查询图表由 ECharts 绘制。浏览器标签页图标在仓库根目录的 `public/favicon.svg`。移植页面时复制整个 `aiAgent/`，其中包括资源和拼图图标的许可声明。

## 维护与验证

业务注释使用中文，优先说明协议单位、状态边界、兼容原因和资源释放时机。协议名保留原拼写。静态图形放入资源目录，格式常量按字段或单位命名，示例数据与第三方许可保留原义。

`npm test` 包含源码资源检查、SSE 分帧、图后正文、Markdown 代码着色、历史恢复和图表数据映射。资源检查覆盖手写脚本、Vue、HTML 和样式，可发现直接粘贴的常见 SVG 路径和内嵌图片。静态检查无法判断一个名称或注释是否足够清楚，这部分仍由代码评阅确认。

独立预览的 `src/main.js` 会装入模拟传输和 `stub/`。生产门户通过 `src/views/ux/aiAgent.vue` 接入并提供登录、语言包和真实 SSE。复核交付时分别执行类型检查、测试、格式检查和生产构建；浏览器中可通过侧栏按钮、图后流式总结和附件提示分别验证资源加载、消息顺序和浮层样式。

## 会话导出

会话标题和历史条目的菜单均把目标会话传给导出函数。浏览器按需加载对应的生成器，全程本地处理。移植时同步安装 `package.json` 中的 `docx` 和 `pdf-lib`。

`lib/export/content.ts` 复用消息正文布局和 Markdown 解析，将每轮提问、回答、图表及表格按顺序整理。图表根据保存的数据和页面共用的 ECharts 配置，在独立画布中关闭动画、绘制 PNG 后释放实例。因此可以直接导出当前没有打开的历史会话。

`word.ts` 将文字、表格和图像分别写成 Word 段落、原生表格和内嵌图片。`pdf.ts` 使用浏览器字体绘制中文及混排文本，在 A4 页边距内换行，图表整块换页，长表按行分页。PDF 页面为图像，需要选取和编辑文字时使用 Word。
